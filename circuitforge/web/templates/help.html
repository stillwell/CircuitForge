User Guide

Simulator

Edit a SPICE deck in the left pane. Pick an analysis (DC operating point, transient, AC sweep, DC sweep) and click Run simulation. Results appear in the right pane. Multiple traces are available via the trace selector.

SPICE syntax

CircuitForge accepts a useful subset of SPICE2/3 syntax:

  • Rxxx n1 n2 value — resistor
  • Cxxx n1 n2 value [IC=v] — capacitor
  • Lxxx n1 n2 value [IC=i] — inductor
  • Vxxx n+ n- value | SIN(...) | PULSE(...) | PWL(...) | AC mag — voltage source
  • Ixxx n+ n- value — current source
  • Dxxx n+ n- model — diode
  • Qxxx nc nb ne model — BJT
  • Mxxx nd ng ns nb model — MOSFET

Library

Browse the bundled component library on the Library page. 108 entries cover passives, semiconductors, op-amps, 7400/4000-series logic, microcontrollers, sensors, and connectors.

REST API

Every action available in this portal is also available via the REST API at /api/v1/. See the README.md for the endpoint index and authentication flow.

Default credentials

The first run creates an admin account with password admin. Replace it immediately by POST /api/v1/auth/register as the admin user.
